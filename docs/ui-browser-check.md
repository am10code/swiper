# UI Browser Check

Короткий сценарий для проверки `main.html` во встроенном браузере на реальных задачах из `mock.swiper`.

## Запуск сервера

Из корня проекта:

```bash
node tools/ui-audit-server.mjs --mock /Users/am10/Downloads/mock.swiper --port 4173
```

Открывать:

```text
http://127.0.0.1:4173/main.html#tasks
http://127.0.0.1:4173/main.html#movement
http://127.0.0.1:4173/main.html#flow
http://127.0.0.1:4173/main.html#cookbooks
```

Сервер:
- отдаёт файлы проекта без кеша;
- подставляет `chrome.storage.local` из `mock.swiper`;
- подставляет `chrome.runtime.getURL`;
- пишет ошибки страницы в `window.__uiErrors`.

## Минимальные проверки

1. `#tasks`: сверху есть рабочая панель `Делать` / `Разобрать`; `Позже` свёрнут, карточки не налезают на нижний ввод.
2. В режиме добавления `FAB` новая задача после отправки формы сразу открывает полную карточку.
3. `#movement`: показывается одна карточка разбора, прогресс вида `1 из N` и кнопки `Назад` / `Дальше`; готовые к исполнению задачи не должны попадать в этот раздел.
4. В `#movement` добавление следующего шага должно требовать текст, явный выбор времени и явный выбор типа.
5. В `#movement`, если перейти на 2-3 карточки вперёд и убрать текущую в `Бэклог`, прогресс остаётся на той же позиции в обновлённой очереди, а не сбрасывается к `1 из N`.
6. `#triage`: показывается одна карточка подготовки, прогресс вида `1 из N` и кнопки `Назад` / `Дальше`.
7. В `#triage` добавление следующего шага требует текст, явный выбор времени и явный выбор типа.
8. Одна и та же карточка не должна одновременно быть первой карточкой в `#movement` и `#triage`.
9. В `#stale` добавление следующего шага требует текст, явный выбор времени и явный выбор типа.
10. В `#stale` перевод в ожидание называется `Перевести в Жду` и требует заполнить кого/чего ждём и дату проверки.
11. `#micro-slots`: карточка показывает ключевое действие, ссылку при наличии, `Выполнить` и `Карточка`; кнопки `Жду` там нет.
12. Action-кнопки рабочих карточек показывают hover/focus-подсказку с результатом нажатия только после задержки около секунды.
13. `#flow`: при выборе короткого окна без подходящих задач показывается явное пустое состояние `Нет задач под 15 минут`, длинная карточка не должна оставаться открытой, верхняя серая полоса режима карточки не видна.
14. Пустой `#flow` предлагает действия: увеличить окно времени, перейти в `Движение`, перейти в `Триаж`.
15. В карточке рутинной регулярки пустое состояние шага: `Рутинное действие выполняется без отдельного следующего шага`.
16. В редактировании карточки виден тип регулярности: `Рутинное действие` / `Работа со следующим шагом`.
17. `#cookbooks`: карта сценариев начинается с `Входящее -> Движение`.
18. В консоли или через браузерную проверку `window.__uiErrors` пустой.

## Остановка

Остановить сервер: `Ctrl+C` в терминале, где он запущен.
